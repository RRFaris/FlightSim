This project is a flight simulator built in Unity, featuring a Cessna 172 aircraft with realistic aerodynamic physics. The flight model simulates lift, drag, and control surface behavior using custom airfoil calculations for each wing surface, including flaperons, elevator, rudder, and horizontal and vertical stabilizers. The simulator supports both keyboard controls and HOTAS (Hands on Throttle and Stick) input, specifically tuned for the Thrustmaster T-Flight HOTAS PS3. Physics features include air density calculation, body drag, rolling resistance, and aerodynamic damping. Players can control throttle, pitch, roll, yaw, flaps, and brakes, with animated control surfaces that visually reflect pilot inputs.
